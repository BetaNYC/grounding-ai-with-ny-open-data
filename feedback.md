# Give us feedback

This site is a draft, and it gets better when people tell us what is wrong or missing. You can help in any of these ways. Each one opens a short form on GitHub, where BetaNYC tracks changes in the open. You need a free [GitHub account](https://github.com/signup).

## Report a correction

Found a wrong link, a site that has closed or moved, or details that are out of date in the [New York data directory](resources/ny-data-portal-registry.md)?

**[Report a correction](https://github.com/BetaNYC/grounding-ai-with-ny-open-data/issues/new?template=data-correction.yml)**

Every county and city page also has a "Report a correction" link at the bottom, with the place already filled in.

## Suggest a missing source

Know of a public data source about New York that the directory doesn't list? Use the same correction form and choose "A source is missing."

**[Suggest a source](https://github.com/BetaNYC/grounding-ai-with-ny-open-data/issues/new?template=data-correction.yml)**

## Share an idea or ask a question

Anything else: a confusing page, a guide you'd like to see, or a question about the tools.

**[Give feedback or ask a question](https://github.com/BetaNYC/grounding-ai-with-ny-open-data/issues/new?template=feedback.yml)**

## Before you post

- Everything posted on GitHub is public. Please don't include passwords, API keys, or personal information about yourself or anyone else.
- A link to an official page that shows the change helps us confirm it.

## Other ways to contribute

- Browse [what others have reported](https://github.com/BetaNYC/grounding-ai-with-ny-open-data/issues).
- If you're comfortable with GitHub, you can suggest an edit directly with a pull request. The pages are plain text files in the [project's repository](https://github.com/BetaNYC/grounding-ai-with-ny-open-data).
