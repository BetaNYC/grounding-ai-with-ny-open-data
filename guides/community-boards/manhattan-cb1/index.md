## What the session covers

Short and ordered, meant to be read straight off the page in a board meeting.

- **One clean answer** to a question the board actually asks.
- **Grounded against ungrounded**, the same question both ways. This is the act that lands.
- **Follow the money** into the district.
- **Their issue, sourced** — whatever the board is currently fighting about, answered from the
  public record.

## What it is honest about

The point is not that the tool is clever. It is that **an answer you can check is worth more than a
fluent one you cannot**, and a board that has been handed confident wrong numbers before will
recognize the difference immediately.

<div class="note" markdown="1">
**Running this for a different board?** Do not edit the CB1 script — copy it. The folder README has
the naming convention (`[borough]-cb[N].md`) and a customization checklist, because every prompt in
the file is pre-filled for this district and will quietly produce the wrong district's data if it is
only half-changed.
