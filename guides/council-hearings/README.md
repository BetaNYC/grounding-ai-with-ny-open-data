# Council hearing transcripts

How BetaNYC turns a NYC Council hearing into an open, speaker-labeled transcript, and why every name and meaning-changing edit needs a source before it is published. The transcripts, data and step-by-step checklist live in their own repository, [BetaNYC/hearings-transcripts](https://github.com/BetaNYC/hearings-transcripts), published at <https://betanyc.github.io/hearings-transcripts/>.

## How this differs from the rest of this repo

Every other folder grounds an AI assistant in the City's open data while you watch. This one goes the other way: it turns what was said in a public hearing into open data, with machine transcription doing the counting, AI assistants doing the naming and editing at BetaNYC's direction, and every judgment checked against a source.
