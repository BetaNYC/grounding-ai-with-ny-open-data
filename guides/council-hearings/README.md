# Council hearing transcripts

How BetaNYC turns a NYC Council hearing into an open, speaker-labeled transcript, and why people check every name and meaning-changing edit before it is published. The transcripts, data and step-by-step checklist live in their own repository, [BetaNYC/hearings-transcripts](https://github.com/BetaNYC/hearings-transcripts), published at <https://betanyc.github.io/hearings-transcripts/>.

## How this differs from the rest of this repo

Every other folder grounds an AI assistant in the City's open data while you watch. This one goes the other way: it turns what was said in a public hearing into open data, with machine transcription doing the counting and people checking the meaning.
