## Notes
- Parcel and map viewer plus the Assessment Database only.
- "Saratoga County Community Health Hub" (org `L31p4Kvi5t2HjDqc` "Saratoga County") is a topical public-health Hub site, not a general data catalog. The Hub search API returned no dataset collection for it.
- The county also publishes a "New York State County Comparisons Data" report page (administrator's office). It is a report, not a dataset.
