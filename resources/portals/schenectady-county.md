# Schenectady County

**Region:** Capital Region · **Entity type:** county · **Status:** no-portal

| Field | Value |
|---|---|
| Portal | No dedicated county-level portal |
| URL | https://www.schenectadycountyny.gov/taxmaps |
| Platform | Schneider Beacon (parcel search); SIMS (login-gated) |
| API type | none |
| API endpoint | — |
| Key required | — |
| Dataset count | — (no catalog) |
| Last verified | 2026-11-05 |
| Evidence | schenectadycounty.com redirects to schenectadycountyny.gov (HTTP 200). The Real Property Tax Service Agency page (/taxmaps) links Beacon (`beacon.schneidercorp.com/Application.aspx?AppID=1277…`). simsgis.org redirects (302) to /Projects/SIMS/Login.aspx. |

## Notes
- GIS work runs through SIMS (simsgis.org), which requires a login.
- Public property lookup is through Schneider Beacon. That is a parcel search, not a dataset catalog.
- See City of Schenectady, which is commonly conflated with the county.

## How to query it
No public API.
